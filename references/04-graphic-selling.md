# 04 · 图文带货：商品卡片 + 合格图文结构公式 + 发布

## 1. 添加商品到视频号橱窗

1. 手机端：创作者中心 → 选品中心 → 任意添加一个品（电脑端上品后可删除该占位品）。
2. 电脑端：百度搜「视频号助手」→ 用视频号微信扫码 → 带货中心 → 橱窗管理 → 添加商品（右上角）→ 商品链接 → 粘贴供应链/商品链接 → 检查库存非 0 → 完成。
3. 想带什么品就添加什么品的链接，可一次加几个或每天加。

> 添加时显示佣金 0% 或 1% 属正常（线下结算品），无需担心。

## 2. 合格图文的结构公式（核心）

一篇能转化的带货图文，图片顺序与文案结构如下：

```
① 封面 1 张          → 抛出痛点问题            【引流】
② 解决问题 2–4 张     → 对痛点给系统方案        【留人埋钩子】
③ 产品 2–4 张        → 卖点/好处/用途全述品     【转化】
④ 购买指南 1–2 张     → 引导下单               【引导】
⑤ 文案与图片顺序贴合，文字不要太多，以图为主；文尾必须有转化话术
⑥ 转化话术紧跟商品卡
```

> 记住：**封面抓眼球 → 中间埋痛点与方案 → 产品图讲透卖点 → 文尾转化 + 商品卡**。

## 3. 插入商品卡片到图文

> 登录的公众号账号需已绑定视频号（见 `02-open-window.md`）。

### 电脑端后台

进入「图片 | 文字」编辑区 → 进入**橱窗** → 选择商品 → **插入商品**。

### 手机端后台

1. 下载「订阅号助手」，登录绑定公众号。
2. 点击「图片 | 文字」→ 点 `+` → 点「商品」→ 选商品 + 选卡片。
3. 发送预览 → 确认效果。

## 4. 群发 vs 发表

- 服务号每月 4 次群发（直达聊天框）；订阅号每天 1 次。
- 前期没粉丝时，**关闭群发开关**，用「发表 / 定时发表」即可。
- **每篇笔记发布间隔 30 分钟 – 1 小时以上**，避免触发限流。

## 5. 发布节奏

- 单号每天 1–8 篇均可，不建议过多（以官方与实测为准）。
- 发布时间：早上不早于 6 点，晚上不晚于 12 点。

## 6. 文案 × 货品结合

原则：让读者看完文案后**主动下单**。回答三个问题：

1. **货品是什么类型？**（功效型 / 情感型 / 刚需型 / 冲动型）
2. **文案给谁看？**（宝妈 / 学生 / 职场人 / 中老年……）
3. **怎么激发情绪？**（痛点共鸣 / 爽点满足 / 场景代入 / 对比反差）

结合人群特点，写容易激发情绪的内容。参见 `assets/prompt-recipes.md`。

## 7. 垂直与原创红线

- 小绿书稳定、优质的前提是**垂直**：内容、图片风格相近，货品与内容高度相关；同账号稳定做一类货品。
- 带商品的小绿书属于**营销行为**，搬运第三方未经授权内容易被举报侵权；应原创，对标学习是拆思路，不是洗稿复制。

- [ ] 文案明确货品类型 + 目标人群 + 情绪钩子
- [ ] 图片 / 文案风格与账号历史内容一致（垂直）
- [ ] 内容为原创 / 已充分去重，未直接搬运
