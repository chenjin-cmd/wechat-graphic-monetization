# 05 · 数据复盘：看板、销售明细、结算与周复盘

## 1. 数据看板入口

- **手机端**：打开「创作者中心」即可看到数据看板。
- **电脑端**：电脑端数据看板分析更细（**最准确**是电脑端视频号助手）。

## 2. 关键认知：销售额 ≠ 佣金

- 「今日数据」里显示的数字是**销售额**，不是纯佣金。
- 图文里展示的「收入」也是**销售额**。
- **佣金结算需等用户确认收货后进行**。

## 3. 三类数据

| 类型 | 看什么 |
| --- | --- |
| 成交数据 | 成交额、订单量、成交趋势 |
| 商品数据 | 各商品的点击 / 转化 / 销量 |
| 用户画像 | 年龄、性别、地域、兴趣 |

## 4. 销售明细查看

- 路径：视频号助手（电脑端）→ 商品管理 → 带货订单 / 带货数据。
- 手机端橱窗出单数据可能不准确，以电脑端为准。

## 5. 佣金结算

- 线上（联盟）：平台自动结算，周期较长。
- 线下（供应链）：出单后填结算表，可出单即填或攒几天一起填；正常 2–3 天到账。
- 预估佣金对不上时：先自查退款 / 售后中 / 取消订单 / 结算日期错误；仍不对则重填结算表让供应商核查。

## 6. 复盘动作（周复盘）

1. **看转化**：哪类商品点击高但成交低 → 商品页或文案问题；成交高 → 复制该选品思路。
2. **看画像**：粉丝画像是否与所选品类匹配，偏离则回调定位。
3. **看趋势**：哪些时段 / 内容形态带货效果好，据此调整发布节奏。
4. **算佣金**：成交额 ≠ 到手；按各商品佣金率 + 结算周期估算真实收益。
5. **看素材**：哪类封面 / 标题 / 正文数据好，沉淀为可复用模板（见 `07-graphic-creation.md` 模块化）。

> 复盘表模板见 `assets/weekly-review-template.md`。

## 7. 数据参考口径

- 商品销量 = **全平台该商品销量**，不是该账号销量。
- 收入展示 = 销售额，非佣金。
- 佣金到手 ≈ 销售额（GMV）× 佣金率 × 平台/结算折扣（具体以实际结算为准）。
