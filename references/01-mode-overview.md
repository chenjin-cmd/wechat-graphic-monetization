# 01 · 模式认知：小绿书带货是什么、怎么做账号规划

## 1. 什么是小绿书

「小绿书」是社区对微信公众号**图文（图片 / 文字消息）**的俗称，形态对标小红书——以图为主、配短文案，依托微信生态分发与变现。

> 微信官方语境中无「小绿书」一词，正式叫法是公众号的「图片消息 / 图文」。给 AI 下指令时两者等价。

## 2. 两种带货模式

| 模式 | 说明 | 适合谁 |
| --- | --- | --- |
| 微信小店（自营） | 自己开店、自己上架、自己发货售后 | 有货源 / 有货权的人 |
| **达人带货**（本技能核心） | 只做「选品上架」，不碰发货售后客服 | 没有货源、想做分佣的人 |

本技能聚焦**达人带货**。

## 3. 达人带货的 7 大特点

1. **不需要**自己运营店铺，只选品上架。
2. **不需要**负责售后、发货。
3. **不需要**提供客服、把关质量。
4. 支持**多店铺商品上架**，手机端即可操作。
5. **橱窗带货无粉丝数限制**；联盟带货需 100 基础粉丝（公众号粉丝）。
6. 依托微信生态，资金、售后、服务有保障。
7. 图文可与带货商品结合发布，**同时赚流量主 + 卖货分佣**。

## 4. 老号 vs 新号（决定开通路径）

- **老号**：此前已把视频号与公众号绑定。
- **新号**：未注册视频号，或注册了但未与公众号绑定。

> 关键差异：老号走「视频号橱窗」路径即可；新号手机端可用橱窗带货，但**电脑端还需额外开通「联盟商品」**（需 100 粉）。详见 `02-open-window.md`。

## 5. 账号主体与类型选择

### 5.1 三个主体

这个项目需要三个主体：**微信、公众号（服务号/订阅号）、视频号橱窗**。其中微信、视频号橱窗、服务号都需要实名；需要直播时视频号也要实名。

### 5.2 服务号 vs 订阅号

| 维度 | 服务号 | 订阅号 |
| --- | --- | --- |
| 流量 | **实测爆的概率更大** | 相对弱，入池更慢，需养号 |
| 门槛 | 需个体户 / 企业营业执照 | 个人身份证即可 |
| 群发 | 每月 4 次 | 每天 1 次 |
| 矩阵 | 相对重 | **轻，更易矩阵放大** |

> 选择建议：追求单号流量用服务号；追求低成本矩阵用订阅号。两者都能出单，结合自身情况选。

### 5.3 账号矩阵逻辑（规划绑定关系）

> 以下为社区实测的账号数量上限，**以微信官方最新规则为准**，仅供矩阵规划参考。

| 主体 | 数量上限 |
| --- | --- |
| 一个人可实名 | 5 个微信号 |
| 一个手机号可绑定管理员 | 5 个公众号 |
| 一个人可实名 | 2 个视频号 |
| 一个人可实名 | N 个视频号橱窗 |
| 个体户营业执照 | 可开 2 个服务号 |
| 公司营业执照 | 可开 50 个服务号（需向公众号申请扩容） |

**核心绑定关系**：一个微信对应一个服务号、对应一个视频号；**同一个微信名下的视频号和服务号才能互相绑定**。规划账号时先理顺「微信-视频号-公众号」的一一对应关系。

## 6. 三种带货形式与门槛

| 形式 | 门槛 |
| --- | --- |
| 橱窗带货 | **无粉丝数限制**（开通联盟后可能需 >100 粉） |
| 短视频带货 | 需超 1000 有效粉丝 |
| 直播带货 | 需超 100 有效粉丝 |

> 图文（小绿书）走「橱窗带货」，门槛最低，是冷启动期最友好的入口。

## 7. 八大垂直赛道

| 赛道 | 特点 / 打法 |
| --- | --- |
| 养生 | 冬季旺季，流量与销量都好（养生茶 / 食补粉等） |
| 美食 | 关键是拍得美，让人垂涎欲滴 |
| 装修 | 以引流或卖小资料为主 |
| 茶叶 | 客单价较高，可带货也可引流私域 |
| 旅行 | 年底旺季，参考小红书旅游打法 |
| 百货 | 带货给流量，出了很多百货号 |
| 成长 / 图书 | 质量要求越来越高，图书佣金率高 |
| 宠物 | 高消费赛道，尽量打垂直 |

> 选赛道原则：高佣金 + 刚需 / 有痛点 + 自己能持续产出素材。同账号**稳定做一类货品**，保持垂直。

## 8. 开通前提

- 需准备与公众号认证主体**一致**的管理员微信视频号（视频号实名主体 = 公众号注册主体）。
- 需缴纳橱窗保证金（金额以官方为准）。
- 收款（提现）银行卡主体需与认证主体一致，认证信息一经提交**不可修改**。

## 9. 决策小结

```
无货源、想赚分佣 → 达人带货
  选账号：服务号(流量大/需执照) vs 订阅号(轻/易矩阵)
  选赛道：8 大赛道挑一个打垂直
  判断老号/新号 → 老号走橱窗；新号电脑端另开联盟(100粉)
```
