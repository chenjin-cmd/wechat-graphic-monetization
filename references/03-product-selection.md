# 03 · 选品：手机端 / 电脑端操作、筛选原则与货源结算

> 选品是带货变现的核心：货品与图文内容的高度相关性，决定了转化与账号垂直度。

## 1. 货源与结算模式（先搞懂再选品）

| 结算模式 | 说明 | 优缺点 |
| --- | --- | --- |
| **线上（选品中心 / 精选联盟）** | 官方结算 | 佣金率相对低、结算周期长（半个月起）、封号佣金可能没 |
| **线下（供应链 / 商家直谈）** | 出单后填表、供应商结算 | 佣金更高、结算更快（可达 T+2），需自己对接 |

> 高佣产品优先走供应链或直接找商家谈线下结算；普通品走选品中心线上结算。本文不提供具体供应链链接，按「选品原则」自行在选品中心 / 商家侧寻找。

## 2. 手机端选品中心

1. 进入手机视频号「带货中心」选品。
2. **带货类目**：可依据畅销货品反向选内容，也可根据热门内容选畅销货品——前提是内容与商品高度相关，能解决读者痛点或满足爽点。
3. **条件筛选**：按显示的筛选条件（类目 / 佣金 / 销量 / 好评率等）筛出符合账号定位的商品。

## 3. 电脑端选品中心

1. 打开网页版视频号助手：<https://channels.weixin.qq.com/login.html>
2. 扫码登录已开通带货权限的账号，进入选品中心，按需筛选。

### 3.1 数据拉取与本地分析

电脑端选货中心可拉取商品数据做本地分析，字段包括：

- 商品 ID、带货 ID、商品标题、售价、佣金（元）、佣金率、近 30 天销量、近 30 天浏览量、近 30 天选品达人数、店名。

**大数据结论（参考）**：
- **佣金率最高** → 图书
- **销量最高** → 食品生鲜

> 具体以选品中心实时数据为准。

## 4. 选品五维原则

一般而言，同时满足以下条件的商品更受欢迎：

1. **好评率高**
2. **支持七天无理由**
3. **销量高**
4. **佣金高**
5. **店铺评分高**

加分项：**运费险、品牌、先用后付、包邮** 等。

> 站在消费者视角反向自问：如果我是买家，我更倾向哪种服务？答案就是选品方向。

## 5. 带货产品方向

- **核心方向**：养生、百货、书籍、绿植、美食。
- **选品口诀**：**高价格、高佣金、刚需 / 有痛点**。

| 维度 | 看什么 |
| --- | --- |
| 佣金 | 佣金率越高越好（1%–50%，多数集中在 30%–50%） |
| 转化 | 月销量、好评率 |
| 服务 | 七天无理由、运费险、先用后付、包邮 |
| 匹配 | 是否与账号内容定位强相关 |

> 不必只挑「很多达人都在带」的货品，结合自己的图文内容创作才是关键。
