# 08 · 限流应对与矩阵放大

> 本章讲「跑通 0-1 之后怎么办」：先解决限流/0 播，再谈矩阵放大。所有操作以微信官方规则为准，**不鼓励任何规避平台机制的违规行为**。

## 1. 限流 / 0 播的现状与原因

- 现象：某个阶段起，带商品卡的新文完全没流量，只有老文在二次推流——通常是平台在调整规则、布局电商生态。
- 原因：大量矩阵号用自动化批量搬运低质内容，导致内容同质化饱和；平台暂时管控营销类流量。

> 结论：**同质化是 0 播的第一元凶**，去重 + 原创 + 换风格是根本解法。

## 2. 商品卡引流方式的多种形态（应对「插卡限流」）

实测中，部分账号「文内直接插商品卡」会被判定为营销文、流量受控；可换用以下**官方功能**作为商品入口（均为合规功能）：

### 2.1 文末引导话术（无留言功能账号）

在文章末尾留引导：

> 例：点击左下方我的头像 → 再点商品橱窗 → 第一个就是文中介绍的商品。

配合：视频号助手 → 橱窗管理 → 把要带的商品**置顶**（顾客点开橱窗第一个看到，无需搜索）。

### 2.2 留言置顶商品链接（有留言功能账号）

1. 文末留引导话术。
2. 发布后：点文章留言图标 → 写留言 → 点链接按钮 → 插入商品 → 发布留言 → 置顶。

> 注意：若点链接无「商品」选项，可能是灰度测试未开放，先按「无留言账号」方式操作。

### 2.3 简介引导（所有账号）

服务号/公众号**个人简介**处写引导：

> 例：文中所有商品均在下方商品橱窗，点击进入后搜索商品名即可购买。

### 2.4 兜底

- 上述方法可正常推流，但若仍没流量，多半是**素材同质化过高 / 不吸引人**——优化素材与文案（回到 `07-graphic-creation.md`）。

## 3. 矩阵放大

### 3.1 核心思路

**加账号 + 加设备 + 加人手，复制你跑通的流程。**

### 3.2 两种矩阵玩法

| 玩法 | 说明 | 风险 |
| --- | --- | --- |
| 搬运去重 | 从小红书/抖音搬素材去重发布 | 同质化限流 + 侵权风险，**不推荐** |
| 原创图文 + 批量自动化上传 | 原创素材，自动化流程提效 | 相对健康，推荐 |

> 无论哪种，**选素材和选品**这两步无法自动化，仍需人工判断。

### 3.3 账号规划

- 先建立「账号矩阵表格」（微信-视频号-公众号一一对应关系），见 `assets/account-matrix-template.md`。
- 把 0-1 全流程复制到第二个号，跑通第二个号即视为矩阵成功。
- 账号数量上限参考 `01-mode-overview.md` 的矩阵逻辑（以官方为准）。

## 4. RPA 自动化（可选提效）

> 泛指 RPA（机器人流程自动化）工具，不绑定具体产品。批量自动化需注意合规与同质化风险。

自动化能解决的三个环节：

1. **自动搜集素材**：按链接/主页批量采集图文。
2. **自动二创**：批量加滤镜、贴纸、背景、边框去重。
3. **自动批量上传**：把处理好的图文批量上传到公众号草稿箱。

无法自动化的环节：**选素材、选品**（需人工判断质量与匹配）。

### 4.1 常见自动化工具链

- 图文采集：RPA 工具 + 浏览器插件（批量采集小红书/抖音图文）。
- 图片去重：RPA 脚本批量加滤镜/贴纸/边框。
- 文案改写：调用 AI 接口批量洗稿（注意：洗稿不等于原创，需 AI 仿写结构）。
- 批量上传：RPA 自动上传草稿箱。

> ⚠️ 合规提醒：批量自动化发布低质同质化内容是平台重点打击对象，可能直接限流/封号。**量不是目的，质 + 去重 + 原创才是**。以官方规则为准。

## 5. 快速自查

- [ ] 0 播先排查同质化，优先去重 + 换风格，而不是加量
- [ ] 商品入口合规：文末话术 / 留言置顶 / 简介引导 / 橱窗置顶
- [ ] 矩阵前先建立账号对应关系表，跑通第二个号才算矩阵
- [ ] 自动化只用于「采集/去重/上传」提效，选品与素材质量仍靠人工
