# 07 · 图文创作与二创：封面、标题、正文 + 模块化 + AI 提效

> 本章是「能不能出单」的核心。核心心法：**好的爆款是「跟」出来的，不是凭空原创出来的**——跟的是结构与规律，抄的是思路，不是内容。

## 0. 合规边界（先读）

「二创 / 去重」要分清两个目的：

| 目的 | 手段 | 说明 |
| --- | --- | --- |
| 降低**同质化限流** | 去重（贴纸/边框/调色/滤镜/字体） | 技术手段，解决平台查重 |
| 避免**版权侵权** | 原创 / AI 仿写结构 | 法律问题，去重**不能**规避 |

> ⚠️ 去重只能缓解「同质化限流」，不能规避「搬运侵权」。大博主图、人物图、风景图、漫画等都可能有版权风险。**优先 AI 仿写结构 + 原创图；去重仅作辅助。**

## 1. 素材来源

- **图片 / 文案素材**：小红书、抖音图文、小绿书本身。
- **下载工具**：去水印工具（如「哼哼猫」等，自行甄别合规性）。
- **去重工具**：美图秀秀、剪映、醒图、稿定设计、PS。
- **去重手段**：贴纸、边框、调色、滤镜、字体。

## 2. 合格图文结构（对应 `04-graphic-selling.md`）

```
封面(痛点) → 解决问题(2-4图) → 产品(2-4图) → 购买指南(1-2图)
文案与图片顺序贴合，文字少、以图为主，文尾必须有转化话术 + 商品卡
```

## 3. 二创三大关键动作

### 3.1 封面：模仿爆款模板

- 好的爆款封面都是**跟、模仿**出来的，不是纯原创。
- 例：养生茶类账号的封面基本一个模板刻出来，只换背景、换产品图、换标题字体。
- 做法：找到垂直赛道的爆款封面 → 提取模板 → 换图、换字、换背景。

### 3.2 标题：有变有不变（核心公式）

爆款标题的结构通常是「主标题 + 副标题」：

```
主标题：脂肪最怕的（X 种）茶
副标题：适合 XXX 人群、XXX 人群必备
```

**要替换的**：形容词、量词、副标题。
**要保留的**：核心关键词（如「脂肪」「茶」）。

> 通用公式：`[痛点关键词] + 最[情绪词]的 + [数量]种 + [品类]`，副标题 `适合[人群]`。
>
> 例：脂肪最怕的茶 → 脂肪最讨厌的 5 种茶饮 → 脂肪最害怕的 8 种茶。

另一类：「（X）厉害的女生都有 XXXX」——保留「厉害」「女生」两个关键词，替换核心内容。

> 心法：**保留关键词，替换修饰成分**，就能批量生成「同款不同面」的爆款标题。

### 3.3 正文：结构清晰、以图为主

- 正文不用太多，关键是结构清晰。
- 拿爆款小绿书 / 小红书图文内容来**改动、替换**，或让 AI 直接仿写 / 原创。
- 小绿书字数建议**不超过 800 字**：太少显得单调，太多影响完读率。

## 4. 模块化心法

任何带货小绿书都万变不离其宗。把爆款素材按「封面 / 标题 / 正文」拆开，分门别类整理，最后**套模板混搭**使用——这也是积累自己爆款素材库的过程。

```
拆解爆款 → 分模块入库（封面库/标题库/正文库/产品图库）
        → 混搭组合 → 去重 → 发布 → 数据复盘 → 回补素材库
```

## 5. 用 AI 提高图文生产效率

### 5.1 提示词四原则

1. **仿写**：丢一段文本，让 AI 仿写（最简单）。
2. **人设**：先给 AI 一个身份（如「资深微信图文带货文案」），效果更好。
3. **具体**：指令要明确，直接说清字数、行数、风格、语气。
4. **修改**：不满意就重新提问，让 AI 多生成几版。

### 5.2 任务拆解

不要一次让 AI 生成整篇笔记（易出错）。**拆成小而完整的任务**：

```
生成正文 = 正文，生成标题 = 标题，生成封面文案 = 封面文案
```

### 5.3 仿写提示词模板

```
你是微信图文带货文案高手。请仿写以下文案的结构与语气，但内容原创、不照搬原文：
- 商品：[货品名称 + 核心卖点]
- 目标人群：[人群]
- 保留：标题的「关键词结构」（如 痛点词 + 品类）
- 替换：形容词、量词、副标题、具体内容
- 要求：口语化、≤800 字、文尾带转化话术
原文结构参考：
[粘贴爆款文案]
```

> 更多文案模板见 `assets/prompt-recipes.md` 与 `assets/title-formulas.md`。

## 6. 修图软件二创实操

### 6.1 单图去重（美图秀秀）

1. 提取爆款图文案 → 美图秀秀「海报设计」→ 模板中心选爆款模板。
2. 编辑：复制文字、粘贴调整、加贴纸、换背景 → 完成去重。

### 6.2 多图拼接

- 美图秀秀「拼图」→ 4 张较主流 → 高级编辑 → 无缝模式 + 调融合度 → 缩放图片。
- 适合零食、汤包、百货类；拼图后同质化概率大大降低。

### 6.3 字幕语录类

- 用「字幕截图生成器」类工具（如 fake-screenshot），换背景图 + 替换字幕。
- 适合书摘、语录、剧照类封面。

### 6.4 高清修复

- 图片模糊时用「wink」等工具做画质修复；wink 还有视频截图、去水印功能。

## 7. 快速自查

- [ ] 封面跟的是爆款模板（换图/字/背景），不是直接搬运
- [ ] 标题用了「保留关键词 + 换修饰」公式
- [ ] 正文 ≤800 字、以图为主、文尾有转化话术
- [ ] 图片已去重（贴纸/边框/调色/滤镜/字体）
- [ ] 内容原创或 AI 仿写结构，未直接照搬他人图文
