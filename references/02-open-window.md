# 02 · 开通橱窗：从实名到可带货的完整路径

> 全程以微信官方最新后台为准。本阶段涉及实名认证、营业执照与提现银行卡主体绑定，务必用真实、一致的主体信息。

## 1. 前置条件

- 一个**微信视频号**（与公众号注册主体一致）。
- 完成**视频号实名认证**。
- 认证主体信息将用于提现校验：**提现银行卡主体必须与认证主体一致**，且认证后不可修改。

## 2. 注册视频号

微信 → 视频号 → 发布任意随拍视频即成功注册视频号。

## 3. 注册公众号（服务号 / 订阅号）

官网：<https://mp.weixin.qq.com/> → 右上角注册。

### 3.1 服务号（需营业执照）

1. 基本信息：填邮箱、验证码、密码。
2. 注册地址：选「中国大陆」。
3. 账号类型：选「服务号」。
4. 信息登记：主体类型选「企业」，企业类型选「个体户」，按提示填主体信息。**服务号管理员可非法人**，用名下有视频号的那个微信做管理员即可。
5. 账号名称 / 简介：随便填，提示需资质就换名字。
6. 绑定视频号：公众号后台 → 设置与开发 → 公众号设置 → 视频号。

> 服务号只支持企业 / 个体户认证。一张个体户营业执照可注册 2 个服务号；公司执照可注册 50 个（需扩容申请）。

### 3.2 订阅号（个人身份证）

1. 基本信息 → 注册地址 → 账号类型选「订阅号」。
2. 信息登记：主体类型选「个人」，按提示填写。
3. 账号名称 / 简介随便填。
4. 绑定视频号：路径同服务号。

### 3.3 营业执照注意

- 个体户执照需在注册第 2 年的 1–6 月于「国家企业信用信息公示系统」做年报申报，并按税务要求登记报税。
- 执照代办：本地工商部门或电商平台寻找代办（自行甄别）。
- 新执照需等 3–5 个工作日，微信才采集到工商信息；老执照若提示异常，先查年报是否正常。

## 4. 实名视频号橱窗

路径：创作者中心 → 带货中心 → 橱窗管理 → 开通橱窗 → 橱窗资质选「个人」→ 缴纳保证金 → 橱窗实名。

- 带货中心左上角切换成**达人带货身份（个人）**，开联盟账户，绑定银行卡（与微信实名同一人）。
- 最后在手机端选品中心任意添加一个商品到橱窗（后期删除，保持橱窗有一件商品即可）。
- **注册过程中所有选择都选个人类型或达人账户，不要选企业/个体户。**

## 5. 账号绑定：三种情况

核心：**同一个微信名下的视频号和服务号才能互相绑定**，不能是微信 A 的视频号去绑微信 B 的服务号。

| 情况 | 操作 |
| --- | --- |
| 有视频号，无公众号 | 注册公众号时，用名下有视频号的微信扫码管理员，法人微信扫法人验证 |
| 无视频号，无公众号 | 微信注册视频号 → 开通橱窗 + 实名 + 交保证金 → 办执照 → 注册服务号（同名微信扫管理员）→ 绑定 |
| 有公众号，无视频号 | 用服务号管理员的微信开通视频号 + 橱窗 + 实名 + 保证金 → 绑定 |

> 管理员微信扫码 = 你要绑定的视频号的那个微信，别扫错。

## 6. 绕过第二个服务号 300 元认证费（可选技巧）

> 注册第二个服务号时，验证方式只剩微信认证（300 元）。正常往下注册，注册完成后会弹「需认证」，不用管，返回主页 → 右下角账号详情 → 法定代表人显示未绑定 → 绑定法人即可绕过。

## 7. 开通联盟达人带货（新号电脑端必需）

- 入口：公众号后台左侧「广告与服务」→ 带货 → 「联盟商品」。
- 条件：**公众号粉丝数 >100**。
- 注意：新号手机端可用橱窗带货，但**电脑端仍需开通「联盟商品」**（需 100 粉）。

## 8. 电脑端 vs 手机端差异

| 端 | 表现 |
| --- | --- |
| 电脑端 | 需 100 粉开通联盟商品 |
| 手机端 | 直接使用视频号橱窗功能 |

## 9. 关键陷阱

- 认证主体 / 提现银行卡信息**不可修改**，务必一次填对。
- 改管理员前先结清资产，否则无法操作。
- 新号别漏了电脑端的「联盟商品」开通，否则电脑后台无法正常选品带货。
- 微信实名、视频号橱窗实名、公众号管理员实名需一致；公众号法人可以是他人。
