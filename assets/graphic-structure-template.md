# 图文结构模板（合格带货小绿书的骨架）

> 用法：写每一篇带货图文时，按此骨架填充。图片顺序与文案顺序一一对应。

## 结构骨架

| 序号 | 图片 | 目的 | 内容要点 |
| --- | --- | --- | --- |
| ① | 封面 1 张 | 引流 | 抛出痛点问题，一句话戳中目标人群 |
| ② | 解决方案 2–4 张 | 留人埋钩子 | 对痛点给出系统性方案，让读者觉得「有救」 |
| ③ | 产品 2–4 张 | 转化 | 卖点 / 好处 / 用途全面述品 |
| ④ | 购买指南 1–2 张 | 引导 | 告诉读者怎么买、在哪买 |
| ⑤ | 文案 | 配合 | 与图片顺序贴合，文字少、以图为主 |
| ⑥ | 转化话术 | 收尾 | 紧跟商品卡，一句话促成下单 |

## 文案结构（配合图片）

```
开头（1-2 句）：戳痛点 / 抛问题，呼应封面
中段（短）：分点给方案，每点对应一张图
结尾（1-2 句）：转化话术 + 商品卡
```

## 完整示例（以养生赛道为例，内容为示例）

```
封面：脂肪最怕的 5 种茶，很多人还不知道
②：这 5 种茶，帮你把「刮油」这件事变得简单
③：第 1 种 X 茶——卖点、好处、适用人群
④：点击下方商品卡，选择适合你的那一款
⑤：文案：冬天囤肉？这 5 种茶……（≤800 字）
⑥：现在下单，包邮 + 七天无理由，试了再说
```

## 自查

- [ ] 封面有痛点钩子
- [ ] 文尾转化话术紧跟商品卡
- [ ] 文字以图为主，不超 800 字
