# 账号矩阵规划表（可复制到你的工作区）

> 用法：矩阵前先理顺「微信-视频号-公众号」一一对应关系。核心：**同一个微信名下的视频号和服务号才能互相绑定**。

## 账号数量上限（以官方为准）

| 主体 | 上限 |
| --- | --- |
| 一人实名微信号 | 5 个 |
| 一人实名视频号 | 2 个 |
| 一人实名视频号橱窗 | N 个 |
| 个体户执照 → 服务号 | 2 个 |
| 公司执照 → 服务号 | 50 个（需扩容） |

## 矩阵复制清单（复制第二个号时逐项打勾）

- [ ] 注册微信 → 注册视频号 → 注册公众号（同微信扫管理员）
- [ ] 视频号开通橱窗 + 实名 + 交保证金
- [ ] 公众号绑定视频号（同主体）
- [ ] 橱窗添加占位商品
- [ ] 选赛道 + 找对标 + 建素材库
- [ ] 发布首篇带货图文
- [ ] 跑通出单闭环

## 提醒

- 矩阵的瓶颈是「选素材 + 选品」仍需人工。
- 批量自动化发布低质同质化内容是平台打击重点，量不是目的。
