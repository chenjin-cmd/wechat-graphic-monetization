# 发布前合规自检清单

> 用法：每篇图文发布前逐项勾选，避免扣信用分 / 违规 / 侵权。

## 内容合规

- [ ] 不夸大功效（无「根治」「秒瘦」「包治」等绝对化词）
- [ ] 不做虚假承诺、不承诺收益
- [ ] 不借热点事件炒作、不卖惨营销
- [ ] 不使用国旗国徽等元素做商业行为
- [ ] 不贬低竞品、不发布混淆信息（不冒用他人店铺/商标/字号）
- [ ] 不泄露他人隐私（人名、联系方式、聊天记录等）

## 图片 / 素材合规

- [ ] 未直接搬运大博主 / 人物 / 明星 / 风景 / 漫画等有版权风险的图
- [ ] 图片已去重（贴纸 / 边框 / 调色 / 滤镜 / 字体 / 拼图）
- [ ] 商用图 / 带版权标识的图未使用
- [ ] 无法判断版权时，已改为原创或 AI 生成图

## 商品合规

- [ ] 商品非违禁品（不涉医疗功效、特许经营、假冒盗版）
- [ ] 商品与内容强相关（不硬塞无关商品）
- [ ] 商品佣金 / 结算方式已确认（线上联盟 vs 线下供应链）
- [ ] 商品链接有效、库存非 0

## 账号操作合规

- [ ] 提现银行卡主体与认证主体一致
- [ ] 不改动已认证的主体信息（不可修改）
- [ ] 敏感信息（微信号 / 手机号 / 银行卡）未写进任何公开内容

## 发布节奏

- [ ] 与上一篇间隔 ≥30 分钟
- [ ] 发布时间在 6:00–24:00 之间
- [ ] 单号当日篇数在合理范围（1–8 篇）

---

> 全部勾选后再发布。信用分满分 12 分，扣到 0 分会暂停橱窗功能且无法回分。
