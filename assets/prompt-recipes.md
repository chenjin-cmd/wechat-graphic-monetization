# 图文带货文案提示词库

> 用法：把「货品类型 / 目标人群 / 情绪钩子」三要素填进模板，让 AI 生成图文文案。坚持原创，不搬运。

## 四类情绪钩子模板

### 1. 痛点型（戳中正在困扰的问题）

```
你是微信图文带货文案高手。请为以下商品写一段小绿书图文文案：
- 商品：[货品名称 + 核心卖点]
- 目标人群：[例如：久坐加班的职场人]
- 钩子：先戳痛点（[具体痛点]），再给方案（该商品如何解决）
- 要求：口语化、100-200 字、结尾带一句自然的行动引导，不做虚假承诺、不夸大功效
```

### 2. 爽点型（满足即时满足 / 获得感）

```
你是微信图文带货文案高手。请为以下商品写一段小绿书图文文案：
- 商品：[货品名称 + 核心卖点]
- 目标人群：[例如：追求性价比的学生党]
- 钩子：直接给爽点（用了之后多爽 / 多值），制造「想要」的冲动
- 要求：口语化、100-200 字、突出获得感与划算，不夸大、不虚假
```

### 3. 场景型（代入具体使用场景）

```
你是微信图文带货文案高手。请为以下商品写一段小绿书图文文案：
- 商品：[货品名称 + 核心卖点]
- 目标人群：[例如：带娃妈妈]
- 钩子：还原一个[具体生活场景]，让读者「对号入座」，自然带出商品
- 要求：有画面感、口语化、100-200 字、结尾自然引导
```

### 4. 对比型（制造反差 / 认知差）

```
你是微信图文带货文案高手。请为以下商品写一段小绿书图文文案：
- 商品：[货品名称 + 核心卖点]
- 目标人群：[例如：对[某品类]有误解的人]
- 钩子：先抛一个常见误区 / 旧认知，再反转给出新选择
- 要求：口语化、100-200 字、反差要真实可信，不贬低他人商品
```

## 通用改写 / 校验提示词

```
请帮我校验并改写这段小绿书带货文案，要求：
1. 明确货品类型、目标人群、情绪钩子是否清晰
2. 是否原创（无搬运感）、是否夸大功效 / 虚假承诺
3. 控制在 100-200 字、口语化
4. 输出：改进版文案 + 一句修改理由
原文：
[粘贴你的文案]
```

## 红线提醒（生成时始终遵守）

- 不夸大功效、不做虚假承诺、不借热点炒作、不卖惨营销。
- 不贬低竞品、不使用国旗国徽等元素进行商业行为。
- 坚持原创，不搬运第三方图文。
