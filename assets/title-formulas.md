# 标题公式库（有变有不变）

> 用法：找到垂直赛道的爆款标题，套公式批量生成「同款不同面」。核心：**保留关键词，替换修饰成分**。

## 公式 1：痛点 + 情绪词 + 数量 + 品类

```
主标题：[痛点关键词]最[情绪词]的[数量]种[品类]
副标题：适合[人群]，[人群]必备
```

| 原爆款 | 保留关键词 | 替换成分 | 生成 |
| --- | --- | --- | --- |
| 脂肪最怕的茶 | 脂肪、茶 | 情绪词/数量 | 脂肪最讨厌的 5 种茶饮 |
| 脂肪最怕的茶 | 脂肪、茶 | 情绪词/数量 | 脂肪最害怕的 8 种茶 |

情绪词库：最怕 / 最讨厌 / 最害怕 / 最恨 / 最离不开 / 最需要
数量词库：3 种 / 5 种 / 8 种 / 10 种

## 公式 2：形容词 + 人群 + 共性结论

```
主标题：[形容词]的[人群]都有/都会/都是 [共性结论]
```

| 原爆款 | 保留关键词 | 替换内容 |
| --- | --- | --- |
| 很厉害的女生都有一个共性：会玩 | 厉害、女生 | 共性结论 |
| 厉害的女人都会「反杀」 | 厉害、女人 | 共性结论 |
| 真正厉害的女孩都是反人性的 | 厉害、女孩 | 共性结论 |

## 公式 3：数字清单型

```
[数字]个[痛点]信号，说明你该[行动]
[数字]件[品类]，[人群]越早知道越好
```

## 生成提示词

```
你是微信图文带货标题高手。请基于以下公式批量生成 10 个标题：
公式：[痛点关键词]最[情绪词]的[数量]种[品类] + 副标题[适合人群]
品类：[你的品类，如 养生茶]
痛点关键词：[如 脂肪/湿气/失眠]
要求：保留关键词，替换情绪词/数量/副标题，口语化、有吸引力、不夸大功效
```

## 红线

- 不夸大功效（不用「根治」「秒瘦」等绝对化词）。
- 不虚假承诺、不借热点炒作。
