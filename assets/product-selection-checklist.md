# 选品自查清单（可复制到你的工作区）

> 用法：在选品中心拉取商品数据后，逐项勾选。全部勾满（或满足大部分）的商品优先考虑。

## A. 佣金维度

- [ ] 佣金率 ≥ 30%（参考多数集中区间）
- [ ] 佣金金额与图文投入产出匹配

## B. 转化维度

- [ ] 好评率高
- [ ] 月销量高
- [ ] 店铺评分高

## C. 服务维度

- [ ] 支持七天无理由
- [ ] 有运费险
- [ ] 支持先用后付
- [ ] 包邮
- [ ] 品牌商品（加分）

## D. 匹配维度（最关键）

- [ ] 与账号内容定位强相关
- [ ] 能解决读者痛点，或满足爽点
- [ ] 图片 / 文案风格与账号历史一致（垂直）
- [ ] 不是「人人都在带」的纯大众货（有自己的内容结合点）
