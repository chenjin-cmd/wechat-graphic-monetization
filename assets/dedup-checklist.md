# 素材去重清单

> 用法：发布前逐项勾选，降低同质化限流风险。**去重不能规避侵权，优先原创 + AI 仿写结构。**

## 去重手段（多选叠加，效果更好）

- [ ] 贴纸（加小挂件 / 角标）
- [ ] 边框（加边框 / 背景缩放形成边框）
- [ ] 调色（对比度、亮度、饱和度微调）
- [ ] 滤镜
- [ ] 字体（换标题字体）
- [ ] 背景（换背景图）
- [ ] 拼图（4 张拼图，无缝模式 + 融合度）
- [ ] 字幕替换（字幕截图生成器换字幕 + 背景）

## 去重工具

| 工具 | 用途 |
| --- | --- |
| 美图秀秀 | 海报设计、拼图、批处理去重 |
| 剪映 | 图片 + GIF 处理 |
| 醒图 / 稿定设计 | 海报模板、去重 |
| wink | 画质修复、去水印、视频截图 |
| 字幕截图生成器 | 语录 / 书摘类封面一键二创 |

## 版权红线（务必遵守）

- [ ] 不用大博主、人物、明星、风景、自制漫画等有版权风险的图直接搬运
- [ ] 商业图片 / 有明确版权标识的图不搬运
- [ ] 无法判断版权风险时，优先原创图或 AI 生成图
- [ ] 去重后仍属于他人作品核心表达的内容，不直接发布

## 判断标准

> 自问：这张图去掉水印、加了滤镜，别人还能一眼认出是「某个作者的作品」吗？如果能，就有侵权风险。

## GIF 处理

- 3 秒 GIF 用 GIF 工具或剪映制作。
- 视频截图去水印可用 wink 等工具。
