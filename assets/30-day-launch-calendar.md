# 30 天冷启动执行日历

> 用法：按天推进，聚焦「开通 → 对标 → 素材 → 首篇 → 复利」。节奏可压缩，但顺序建议保持。

## 第 1 周：搭好账号（Day 1–7）

| 天 | 任务 |
| --- | --- |
| Day 1 | 理顺绑定关系，注册 2 个公众号 + 对应视频号并绑定 |
| Day 2 | 视频号橱窗实名 + 交保证金 + 添加占位商品 |
| Day 3 | 选定赛道，在小红书找 5 个对标账号 |
| Day 4 | 在订阅号 / 服务号找 5 个对标账号 |
| Day 5 | 对标拆解：搜集 10 篇图片素材 |
| Day 6 | 对标拆解：搜集 10 篇文案素材 |
| Day 7 | 对标拆解：搜集 10 篇标题素材 |

## 第 2 周：跑通首篇（Day 8–14）

| 天 | 任务 |
| --- | --- |
| Day 8 | 选品：按「高佣 + 刚需 + 痛点」选定首款商品 |
| Day 9 | 做首篇：封面（痛点）→ 方案 → 产品 → 购买指南 |
| Day 10 | 图片去重 + 标题套公式 + 正文 ≤800 字 |
| Day 11 | 插入商品卡 + 文尾转化话术，发布首篇 |
| Day 12 | 保持日更 1–2 篇，观察数据 |
| Day 13 | 复刻数据最好的那篇（模块化） |
| Day 14 | 周复盘：哪类封面 / 标题 / 商品数据好 |

## 第 3 周：放大与优化（Day 15–21）

| 天 | 任务 |
| --- | --- |
| Day 15–18 | 复制数据好的模板，日更 3–5 篇 |
| Day 19 | 排查 0 播：去重 + 换风格 + 换品 |
| Day 20 | 商品入口优化（文末话术 / 留言置顶 / 简介引导） |
| Day 21 | 周复盘 + 结算核对 |

## 第 4 周：矩阵复制（Day 22–30）

| 天 | 任务 |
| --- | --- |
| Day 22–25 | 建立账号矩阵表，复制流程到第二个号 |
| Day 26–29 | 双号并行，跑通第二个号出单闭环 |
| Day 30 | 月度复盘：沉淀爆款素材库 + 下月选品计划 |

## 关键提醒

- 0 播很正常，坚持发 + 换风格，有 1 篇起飞就能带动。
- 涨粉不是目的，出单才是；不需要刻意涨粉。
